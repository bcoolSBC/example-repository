Year 10 Digital Tech: Publishing on GitHub Pages

Follow these steps to turn your HTML code into a live website on the Internet!

1 Create a New GitHub Repository

Log in to GitHub.com and click the + icon in the top right, then select New repository.

  • Repository Name: Give it a short name (e.g., my-first-website).
  • Visibility: Select Public (GitHub Pages requires public repositories on free student accounts).
  • Initialize: Check the box that says Add a README file.
  • Click Create repository.

2 Add Your index.html File

The homepage of every web server must be named exactly index.html (all lowercase).

  • In your new repository, click Add file → Create new file (or Upload files if you already wrote your code).
  • In the filename box, type index.html.
  • Paste your HTML code into the editor.
  • Scroll to the bottom and click Commit changes... to save your file.
💡 Pro Tip: Inspect the code of this page to see how HTML tags like <section>, <h2>, and <ul> structure the content!

3 Enable GitHub Pages

Now tell GitHub to publish your repository root folder as a live website:

  1. Click on the Settings tab at the top of your repository page.
  2. In the left menu sidebar, click Pages (under "Code and automation").
  3. Under Build and deployment > Branch:
    • Select main (or master) as the branch.
    • Keep the folder set to /(root).
  4. Click Save.

4 View Your Live Website!

Wait 1–2 minutes for GitHub to build your website, then refresh the Pages settings screen.

You will see a live web address banner formatted like this:

https://<your-username>.github.io/<repository-name>/

Click the link to test your live website on the internet!
